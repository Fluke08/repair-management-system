
# Repair Request System

A web application for submitting and tracking equipment repair requests.

## Features

- User authentication
- Repair request management
- Equipment status tracking
- Repair category management
- Repair status workflow

## Tech Stack

- PHP
- MySQL / MariaDB
- PDO
- Bootstrap 5
- JavaScript
- jQuery
- DataTables
- SweetAlert2

## Requirements

- PHP 8.2 or compatible version
- MySQL / MariaDB
- Apache web server
- XAMPP or an equivalent local development environment

## Installation

1. Clone or download this repository.
2. Create a database named `purephp`.
3. Import `database/purephp.sql` into the database.
4. Copy `config/database.example.php` to `config/database.php`.
5. Update the database credentials in `config/database.php`.
6. Place the project in your web server directory.
7. Open the project through your local web server.

## Demo Account

No default account is included.
Register a test account through the application, if registration is enabled.

## Security

This repository contains sample database structure and reference data.
Do not use real credentials or production data in a public repository.
